Value iteration: the algorithm  
Value of s at k timesteps to go: Vk(s)                                                    Vk+1(s)  
  
  1        Initialize: V0(s) = 0 for all s                                        a  
  
        s, a  
  2        V1(s) ← maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ V0(s′) ]  
        s, a, s′  
  
  3        V2(s) ← maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ V1(s′) ]                       Vk(s′)  
  
  
  4        …  
  
  
  5        Vk+1(s) ← maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ Vk(s′) ]

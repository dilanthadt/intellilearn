Value iteration: the Bellman equations  
We’re going to calculate V\* and/or Q\* by repeatedly doing one step expectimax.  
Notice that V\* and Q\* can be defined recursively:                                                   s  
  
  
        a  
        s, a  
    V\*(s) = maxa Q\*(s, a)  
        s, a, s′  
    Q\*(s, a) = Σs′ T(s, a, s′) [ R(s, a, s′) + γ V\*(s′) ]  
        s′  
    V\*(s) = maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ V\*(s′) ]  
  
  
  
These are called the Bellman equations.  
Note that they do not reference the optimal policy π\*.

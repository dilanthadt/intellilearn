### L12 – Markov Decision Processes — page 84

Summary  
MDP               M = (S, A, T, R): states, actions, transition probabilities and rewards. Outcomes depend only on the  
        current state and action.  
  
  
Utility           Discounted sum of rewards. The discount γ trades off how much reward against how soon.  
  
  
  
  
Value iteration   Start from V₀ = 0 and repeatedly apply the Bellman update until the values stop changing.  
  
  
  
  
Policy            Extract π\* from V\* with one step of expectimax (argmax instead of max).

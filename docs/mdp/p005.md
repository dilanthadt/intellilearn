### L12 – Markov Decision Processes — page 5

STOCHASTIC DOMAINS  
  
  
  
Example: stochastic grid world  
▪     A maze like problem  
      ▪     The agent lives in a grid  
      ▪     Walls block the agent’s path  
▪     Noisy movement: actions do not always go as planned  
      ▪     80% of the time, the action North takes the agent North (if there is  
        no wall there)  
      ▪     10% of the time, North takes the agent West; 10% East  
      ▪     If there is a wall in the direction the agent would have been taken,  
        the agent stays put  
▪     The agent receives rewards each time step  
      ▪     Small “living” reward each step (can be negative)  
      ▪     Big rewards come at the end (good or bad)  
▪     Goal: maximize the (discounted) sum of rewards

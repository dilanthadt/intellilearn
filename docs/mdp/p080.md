SOLVING MDPS · VALUE ITERATION  
  
  
  
Bellman equations and value iteration  
Bellman equations characterize the optimal values:  
  
  
        V\*(s) = maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ V\*(s′) ]  
  
Value iteration computes them:  
  
  
        Vk+1(s) ← maxa Σs′ T(s, a, s′) [ R(s, a, s′) + γ Vk(s′) ]  
  
  
Value iteration is just a fixed point solution method … though the Vk vectors are also interpretable as time limited  
values

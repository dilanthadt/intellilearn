### L04 – Local Search & Optimization — page 6

Local Search  
• Use a single current state and move only to neighbours.  
  • No track of the paths  
  • No track of the set of states that have been reached  
• Not systematic ➔ Might never explore a portion of the search  
  space where the solution exists.  
  
• Advantages:  
  • Use little space  
  • Can find reasonable solutions in large or infinite (continuous) state  
    spaces for which the other algorithms are unsuitable.

Simulated Annealing  
• Based on a metallurgical metaphor.  
• Annealing: harden metals and glass by heating them to a high  
  temperature and then gradually cooling them.  
• Start with a temperature set very high and slowly reduce it.  
  
• Run hill-climbing with the twist that you can occasionally replace  
  the current state with a worse state based on the current  
  temperature and how much worse the new state is.  
• At the start, make lots of moves and then gradually slow down.

### Lecture 2 – Intelligent Agents — page 30

Simple Reflex Agents  
• Simplest kind of agent  
• Actions depend only on present percepts ignoring the history  
• Limited Intelligence  
• Works best in an observable environment  
• E.g., Vacuum agent (because its decision is based only on the  
  current location and on whether that location contains dirt.)

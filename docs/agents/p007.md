### Lecture 2 – Intelligent Agents — page 7

The Agent Function  
• Maps the agent’s percept sequence to an action  
• Percept sequence - The complete history of everything an  
  agent has perceived so far.  
• An ideal mapping specifies an agent’s actions for any given  
  percept sequence.  
• Agent Program - The implementation of the agent function.  
• The effectiveness of the agent function is measured through a  
  performance measure.

### Lecture 2 – Intelligent Agents — page 20

Properties of Task Environments  
• Observed from the agent’s point of view  
• Fully observable vs. partially observable  
   • Fully observable: The agent’s sensors give access to the complete state of the  
     environment at each point in time.  
   • Fully observable environments are convenient.  
   • An environment might be partially observable because of noisy and inaccurate  
     sensors or because parts of the state are simply missing from the sensor data  
   • E.g.,  
      • A vacuum agent with only a local dirt sensor cannot tell whether dirt is in other squares.  
      • An automated taxi cannot see what other drivers are thinking.  
   • A task environment is effectively fully observable if the sensors detect all  
     aspects relevant to the choice of action; relevance, in turn, depends on the  
    performance measure.

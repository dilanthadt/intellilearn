Query 4: A diagnostic query with two observations  
Question. Both John and Mary have called. What is the probability that there is a burglary?  
Now we reason backwards, from effects to a cause. This is the query the network was built for. Using  
normalisation, we need the unnormalised joint P(B, j, m) for B = true and for B = false, with E and A  
summed out.  
        P(B \| j, m) = α · P(B) · Σₑ P(e) · Σₐ P(a \| B, e) · P(j \| a) · P(m \| a)  
The innermost sum over A appears four times, once for each (B, E) pair, so compute those first. Each  
one has the form P(a \| B, E) · 0.90 · 0.70 + P(¬a \| B, E) · 0.05 · 0.01, that is P(a \| B, E) · 0.63 + P(¬a \| B, E) ·  
0.0005.  
  
  
        B             E            P(a \| B, E)                          Inner sum over A  
        true         true              0.95                   0.95 × 0.63 + 0.05 × 0.0005 = 0.598525  
        true         false             0.94                   0.94 × 0.63 + 0.06 × 0.0005 = 0.592230  
        false         true              0.29                   0.29 × 0.63 + 0.71 × 0.0005 = 0.183055  
        false         false            0.001                  0.001 × 0.63 + 0.999 × 0.0005 = 0.001130  
  
  
Case B = true:  
        P(b, j, m) = 0.001 × [0.002 × 0.598525 + 0.998 × 0.592230]  
        = 0.001 × [0.001197 + 0.591046] = 0.001 × 0.592243 ≈ 0.000592  
Case B = false:  
        P(¬b, j, m) = 0.999 × [0.002 × 0.183055 + 0.998 × 0.001130]  
        = 0.999 × [0.000366 + 0.001127] = 0.999 × 0.001493 ≈ 0.001492  
Normalise:  
        α = 1 / (0.000592 + 0.001492) = 1 / 0.002084  
        P(b \| j, m) = 0.000592 / 0.002084 ≈ 0.284               P(¬b \| j, m) ≈ 0.716  
Interpretation. Before any calls the belief in a burglary was 0.001. Two independent reports raise it to  
about 0.284, roughly 280 times higher. Yet a burglary is still the less likely explanation. Most of the  
remaining probability comes from the alarm going off for no reason at all (the 0.001 in the last CPT row)  
and both neighbours faithfully reporting it. The mathematics captures something a human would find  
hard to judge by intuition alone.  
The same computation with the roles of B and E swapped gives P(e \| j, m) ≈ 0.176. So after two calls an  
earthquake is also a serious contender, and the two alarm causes together still leave over half the  
probability on the plain false alarm.

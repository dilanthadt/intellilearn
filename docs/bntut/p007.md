  4. P(b, m) = P(b) · P(m \| b) = 0.001 × 0.659 ≈ 0.000659 and P(m) ≈ 0.0117, so P(b \| m) ≈ 0.056.  
  5. P(e, j, m) = P(e) · [P(b) · 0.598525 + P(¬b) · 0.183055] = 0.002 × 0.183470 ≈ 0.000367. Dividing by  
     P(j, m) ≈ 0.002084 gives P(e \| j, m) ≈ 0.176.

### Logical Agents II — page 37

Satisfiability  
A sentence is satisfiable if it is true in, or satisfied by, some model  
 Satisfiability can be checked by enumerating the possible models until one is  
found that satisfies the sentence  
  
Validity and satisfiability are connected:  
  
α is valid if ¬α is unsatisfiable; contrapositively, α is satisfiable iff ¬α is not valid

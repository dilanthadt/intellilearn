### Logical Agents II — page 27

Propositional Logic - semantics  
Defines the rules for determining the truth of a sentence with respect to a  
particular model  
  
Models in propositional logic - simply sets the truth value—true or false— for  
every proposition symbol  
  
E.g. proposition symbols P,Q, R  
  
One possible model m1 = {P= true, Q=true, R=false}

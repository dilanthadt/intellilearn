 Deciding conditional independence is hard in noncausal directions  
  (Causal models and conditional independence seem hardwired for  
  humans!)  
 A causal model (links from cause to effects) usually is more compact than a  
  diagnostic (links from effects to causes) model.  
 So it’s better to order variables as, root causes first, then variables they  
  influence and so on…

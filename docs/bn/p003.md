### L11 – Bayesian Networks — page 3

Bayesian networks  
 A Bayesian network is a graph with the following:  
  1. Nodes: Set of random variables  
  
  2. Directed links: The intuitive meaning of a link from node X  
   to node Y is that X has a direct influence on Y  
  3. Each node has a conditional probability table (CPT) that  
   quantifies the effects that the parent have on the node.  
  4. The graph has no directed cycles (DAG)

Example  
   Suppose we choose the ordering M, J, A, B, E  
  
  
  
  
  
P(J \| M) = P(J)?  
No  
P(A \| J, M) = P(A \| J)? P(A \| J, M) = P(A)? No  
P(B \| A, J, M) = P(B \| A)? Yes  
P(B \| A, J, M) = P(B)? No  
P(E \| B, A ,J, M) = P(E \| A)? No  
P(E \| B, A, J, M) = P(E \| A, B)? Yes

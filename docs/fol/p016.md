### First-Order Logic — page 16

A common mistake to avoid  
 Typically, ⇒ is the main connective with ∀  
     A universal quantifier is also equivalent to a set of implications  
     over all objects  
  
 Common mistake: using ∧ as the main connective with ∀:  
 ∀x At(x, UoM) ∧ Smart(x)  
 means “Everyone is at UoM and everyone is smart”  
 Leads to overly strong statements

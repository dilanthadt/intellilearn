### First-Order Logic — page 9

Interpretations  
    An intended interpretation specifies  
      Which object is referred by a constant symbol  
        Richard refers to Richard the Lionheart  
      Which relation is referred by a predicate symbol  
        Brother refers to brotherhood relation  
      Which function is referred by a function symbol  
        leftLeg refers to the left leg function  
    Truth should be defined in terms of all possible models  
    and all possible interpretations

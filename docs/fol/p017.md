### First-Order Logic — page 17

Existential quantification  
∃\<variables\> \<sentence\>  
Someone at UoM is smart:  
  ∃x At(x, UoM) ∧ Smart(x)  
∃x P is true in a model m iff P is true with x being some possible  
 object in the model  
  Roughly speaking, equivalent to the disjunction of instantiations of P  
    At(Dan, UoM) ∧ Smart(Dan)  
  ∨ At(Richard, UoM) ∧ Smart(Richard)  
  ∨ At(Ben, UoM) ∧ Smart(Ben)  
  ∨ ...

Using First Order Logic  
 Assertions  
     Sentences that are added to the KB using TELL  
       TELL(KB, King(John))  
       TELL(KB, ∀x King(x) ⇒ Person(x))  
 Queries (goals)  
     Ask questions of the KB using ASK  
       ASK(KB, King(John))  
     Quantified queries (Answer is a substitution or a binding list)  
       ASK(KB, ∃x Person(x))

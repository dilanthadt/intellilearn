THE PROBLEM WITH TABLES  
  
A table learns nothing about similar states  
  
        Too many states  
        Even small boards have more  
        states than you could ever visit.  
        ≠  
        No generalisation  
    State 1: ghost adjacent        State 2: ghost one step further  
        Each row is learned separately.  
        Similar states share nothing.  
  
  
  
To a table these are unrelated rows, so state 2 starts from scratch.

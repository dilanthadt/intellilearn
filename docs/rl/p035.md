THE TD ERROR  
  
One formula to remember: old estimate + α × surprise  
  
  
        δ = [ r + γ V(s′) ] − V(s)                                  V(s) ← V(s) + α δ  
  
        what this experience says minus what I currently believe  
  
  
        old V(s) = 0               δ = 6, α = 0.5                 sample = 6  
  
  
        0                           3                            6  
  
        new V(s) = 0 + 0.5 × 6 = 3

### L13 – Reinforcement Learning — page 64

SARSA VERSUS Q LEARNING  
  
The two rules differ in one term  
  
  Q learning · off policy  
  
        Q(s, a) ← Q(s, a) + α [ r + γ maxa′ Q(s′, a′) − Q(s, a) ]  
  
  
  SARSA · on policy  
  
        Q(s, a) ← Q(s, a) + α [ r + γ Q(s′, a′) − Q(s, a) ]  
  
  
        a′ = the action actually taken next, exploration included

### L06 – Logical Agents (overview) — page 14

Describing the Environment  
  
Properties of the Wumpus World  
• Partially observable: The Wumpus world in AI is partially  
  observable because the agent can only sense the immediate  
  surroundings, such as an adjacent room.  
• Deterministic: It is deterministic because the result and end of the  
  world are already known.  
• Sequential: It is sequential because the order is essential.  
• Static: It is motionless because Wumpus and Pits are not moving.  
• Discrete: The surroundings are distinct.  
• One agent: The environment is a single agent because we only  
  have one agent, and Wumpus is not regarded as an agent.

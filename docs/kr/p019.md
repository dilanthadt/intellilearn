Time and Event Calculus  
 Event calculus predicates  
     T(f, t) Fluent f is true at time t  
     Happens(e, i) Event e happens over the time interval i  
     Initiates(e, f, t) Event e causes fluent f to start to hold at time  
     t  
     Terminates(e, f, t) Event e causes fluent f to cease to hold at  
     time t  
     Clipped(f, i) Fluent f ceases to be true at some point during  
     time interval i  
     Restored (f, i) Fluent f becomes true sometime during time  
     interval i

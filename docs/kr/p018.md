Time and Event Calculus  
 When there are multiple agents, actions have durations,  
 and can overlap with each other….  
 Event calculus to the rescue  
     Fluents hold at points in time  
     Reasoning is done over intervals of time  
 T – the predicate that is used to assert that a fluent is  
 actually true at some point in time  
     T(At(Shiva , Colombo), t)  
 T can be extended to work over intervals  
     T(f, (t1, t2)) ⇔ [∀ t (t1 ≤ t \< t2) ⇒ T(f, t)]  
 Events can be described as instances of event categories  
     E1 ∈ Flyings(Shiva , Colombo, Jaffna)

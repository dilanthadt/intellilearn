### L10 – Uncertainty & Probability — page 18

Random variables  
●   A random variable is a variable whose possible values (Domain ) are  
    numerical or categorical outcomes of a random phenomenon.  
     ○   E.g. X = outcome of a roll of a dice.  
     ○   Domain(X) = {1, 2, 3, 4, 5, 6}  
●   A Random variable can be boolean, discrete, continuous or categorical,  
    depending on its domain.  
●   P induces a probability distribution for any r.v. X:  
     ○   e.g., P(X=1) =1/6, P(X=2) =1/6, …, P(X=6) =1/6

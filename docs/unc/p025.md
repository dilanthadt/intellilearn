### L10 – Uncertainty & Probability — page 25

Notation  
●   P(X1 = x1, X2 = x2, …, Xn = xn) refers to a single entry (atomic event) in the joint  
    probability distribution table  
     ○   Shorthand: P(x1, x2, …, xn)  
●   P(X1, X2, …, Xn) refers to the entire joint probability distribution table  
●   P(A) can also refer to the probability of an event  
     ○   E.g., X1 = x1 is an event

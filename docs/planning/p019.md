ADL (Action Description Language)  
• In recent years, it has been noted that STRIPS is  
  not sufficiently expressive  
  
• This has resulted in many language variants.  
  ADL is one of them.  
  
• The same Fly action in ADL  
  
Action(Fly(p:Plane, from:Airport, to:Airport),  
   PRECOND: At (p, from) ∧ (from ≠ to)  
   EFFECT: ¬At (p, from) ∧ At (p, to)

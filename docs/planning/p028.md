### Lecture 9 – Planning — page 28

   Forward state-space search  
• Also called progression planning  
  
• Starting from the initial state, consider sequences of  
  actions that reach the goal  
  
• For a given state, all actions whose preconditions are  
  satisfied, are applicable  
   • The successor state is determined by adding the positive  
     effect literals and deleting the negative effect literals to the  
     current state  
  
• Goal test checks if the current state satisfies the goal

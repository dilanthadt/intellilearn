        PDDL Semantics  
• Starting at state s, result of executing action a is a state  
  s’  
   – Contains (+)ve literals in the effect of a  
   – (-)ve literals are removed  
   – Otherwise same as s  
  
• Assumption – every literal not mentioned in the effect  
  remains unchanged  
   – Avoids frame problem  
  
• Solution to the planning problem – an action sequence  
  that, when executed, results in a state that satisfies the  
  goal

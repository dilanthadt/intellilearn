### L05 – Constraint Satisfaction Problems — page 6

Constraint Satisfaction Problems(CSPs)  
• An assignment that doesn’t violate any constraint is called a  
  consistent or legal assignment.  
• If every variable is assigned a value, it is a complete  
  assignment.  
  
• A solution to a CSP is a complete and consistent assignment.  
  • E.g., One that has all variables assigned with values and satisfies all  
    the constraints

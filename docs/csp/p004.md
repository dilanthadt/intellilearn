### L05 – Constraint Satisfaction Problems — page 4

Constraint Satisfaction Problems(CSPs)  
• CSP is defined by  
   • A set of variables X= {X1 , X2 , … , Xn}, where each Xi, can take values  
     from domain Di  
   • A set of constraints, C= {C1 , C2 ,…,Cm}  
• A domain, Di, consists of a set of allowable values, {v1 , v2 ,…,vk}  
  for variable Xi  
• E.g., if Xi is Boolean the domain is {true, false}  
• Different variables can have different domains of different sizes.

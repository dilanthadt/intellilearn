### L05 – Constraint Satisfaction Problems — page 13

Local Search for CSPs  
• Hill-climbing, simulated annealing, and others can be used for  
  CSPs  
   • Typically work with "complete" states, i.e., all variables assigned  
• To apply to CSPs:  
   • Allow states with unsatisfied constraints  
   • Operators reassign variable values  
  
• Initial state: Some assignment to all variables. E.g., random  
• Successor function: Usually changes the value of a single  
  variable  
• Variable selection: Randomly select any conflicted variable  
• Value selection by min-conflicts heuristic:  
   • Choose a value that violates the fewest constraints  
      • E.g., hill-climb with h(n) = total number of violated constraints

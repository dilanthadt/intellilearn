## 🚀 Local Quick Start

### 1-Click Launch (Windows)
Double-click \start.bat\. It will launch the local HTTP server and automatically open your default browser.

### Python Server
\\\ash
python serve.py
\\\
Opens at [http://localhost:3613](http://localhost:3613).

### Node.js / NPM
\\\ash
npm start
\\\

## 📚 Features & Course Modules

- **14 Topic Practice Quizzes**: 140 curated questions with step-by-step logic, option-specific notes, and formulas.
- **5 Exam Readiness Papers**: 50 timed mock exam questions with real-time countdown timer and model solutions.
- **Slide & Textbook Drawer**: Docks lecture slide pages and diagrams right beside the questions when clicking citations.
- **Pristine Math Typesetting**: KaTeX rendering for all logic and probability formulas.
- **Local Progress Persistence**: Progress and exam scores automatically saved in \localStorage\.
